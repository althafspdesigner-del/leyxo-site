# leyxo.com

Coming-soon waitlist page for Leyxo, served by GitHub Pages at https://leyxo.com. Built in The Wink identity (Acid Lime): lime ground, Bricolage Grotesque and Instrument Sans, cobalt wink. A 3D ring of 14 brand-mark cards fans out on load, spins continuously and speeds up when you scroll.

- `index.html`: the whole page (English and Arabic, language toggle, notify-me form that opens an email to hello@leyxo.com)
- `assets/cards/`: the 7 text-free card designs (x, o and xo pattern on brand colours), each used twice in the ring
- `assets/`: Wink logo, Wink and Grin faces, favicon set from the monogram, social share image
- Fonts load from Google Fonts (SIL Open Font Licence)
- `CNAME`: the custom domain
