# leyxo.com

Coming-soon waitlist page for Leyxo, served by GitHub Pages at https://leyxo.com. Built in The Wink identity (Acid Lime) with the tic-tac-toe second theme: one playable round where each of the nine squares is a Leyxo service, described when the visitor plays it. O plays its best move and can win.

- `index.html`: the whole page (English, inline SVG logo, face and icons, notify-me form that opens an email to hello@leyxo.com)
- `assets/`: Wink logo, Wink and Grin faces, favicon set from the monogram, social share image
- Fonts load from Google Fonts (SIL Open Font Licence)
- `CNAME`: the custom domain
