# leyxo.com

Coming-soon waitlist page for Leyxo, served by GitHub Pages at https://leyxo.com. Built in The Wink identity (Acid Lime) with the tic-tac-toe second theme: a playable board where each of the nine squares is a Leyxo service or project step, revealed as the visitor plays. Three rounds, and x never loses.

- `index.html`: the whole page (English, inline SVG logo, face and icons, notify-me form that opens an email to hello@leyxo.com)
- `assets/`: Wink logo, Wink and Grin faces, favicon set from the monogram, social share image
- Fonts load from Google Fonts (SIL Open Font Licence)
- `CNAME`: the custom domain
